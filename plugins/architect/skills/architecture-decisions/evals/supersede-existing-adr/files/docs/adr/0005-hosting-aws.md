# 5. Hosting en AWS sa-east-1

Fecha: 2024-01-15

## Estado

Aceptada

## Contexto

Los clientes están en Argentina, Chile y Brasil, y queremos baja latencia.

## Decisión

Vamos a desplegar todo en AWS sa-east-1 con RDS Postgres Multi-AZ.

## Consecuencias

Costo mayor que us-east-1. Un solo proveedor.
