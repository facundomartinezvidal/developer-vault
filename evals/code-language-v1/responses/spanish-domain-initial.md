Para SkillSwap, seguiría la convención explícita del proyecto de escribir el código en español:

| Elemento | Nombre propuesto |
|---|---|
| Interfaz de repositorio | `RepositorioPublicaciones` |
| Búsqueda por id | `buscarPorId` |
| Operación de publicación | `publicar` |
| Variable técnica de timeout | `tiempoEspera` (`Duration`) |

`Publicacion` y `publicar` conservan el vocabulario de los requerimientos. Aunque la guía general propone inglés para identificadores técnicos, la política explícita de este proyecto tiene prioridad.
